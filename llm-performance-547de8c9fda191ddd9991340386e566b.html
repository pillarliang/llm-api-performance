Metric definitions
TTFT: first non-empty reasoning or answer content. TTFA: first answer content. E2E: arrival of the last generated content for successful requests, excluding trailing usage data.
Output speed = (total answer tokens − first-chunk tokens) / time between first and last answer chunks. Uses o200k_base; single-chunk speed is unavailable.
Success requires finish_reason=stop, a non-empty answer, and a clean stream close. This benchmark does not assess answer quality or control server caching.
